# Bubbly

バブルチャートで学習や投資などの情報を視覚的に整理・管理するWebアプリケーション

## 概要

Bubblyは、さまざまな情報（学習トピック、投資ポートフォリオ、プロジェクト管理など）をバブルチャートとして視覚化し、直感的に整理できるツールです。バブルのサイズや色、位置で情報の重要度や関連性を表現できます。

## 主な機能

- **バブルチャートによる可視化**: 情報をバブルとして表示し、直感的に把握
- **学習管理**: 学習トピックの進捗や重要度を視覚化
- **投資情報整理**: 投資ポートフォリオや資産配分を可視化
- **カスタマイズ可能**: バブルのサイズ、色、ラベルなどをカスタマイズ
- **インタラクティブな操作**: ドラッグ&ドロップでバブルを移動・整理
- **データの保存・読み込み**: 作成したチャートを保存して後で編集可能

## インストール

### 前提条件

- Node.js (バージョン 16以上推奨)
- npm または yarn

### セットアップ

```bash
# リポジトリをクローン
git clone https://github.com/tata-took/Bubbly.git
cd Bubbly

# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev
```

ブラウザで `http://localhost:3000` にアクセスしてください。

## 使い方

### 1. バブルの作成

1. 画面上の「新規バブル作成」ボタンをクリック
2. 以下の情報を入力：
   - **タイトル**: バブルのラベル
   - **カテゴリー**: 学習、投資、その他
   - **サイズ**: 重要度や金額などを表す（1-100）
   - **色**: カテゴリーや状態を表す
   - **説明**: 詳細情報（任意）

3. 「作成」をクリックしてバブルを追加

### 2. バブルの編集

- バブルをクリックして詳細を表示
- 編集アイコンをクリックして内容を変更
- ドラッグ&ドロップでバブルを移動

### 3. バブルの整理

- **グルーピング**: 関連するバブルを近くに配置
- **サイズ調整**: 重要度に応じてサイズを変更
- **色分け**: カテゴリーごとに色を統一

### 4. データの保存

- 「保存」ボタンをクリックしてチャートを保存
- ローカルストレージまたはクラウドに保存可能
- JSONファイルとしてエクスポート可能

## 使用例

### 学習管理

- 各バブルを学習トピックとして作成
- サイズ: 学習時間や重要度
- 色: 習得度（赤=未着手、黄=学習中、緑=習得済み）
- 位置: 関連トピックを近くに配置

### 投資ポートフォリオ

- 各バブルを投資先として作成
- サイズ: 投資金額
- 色: 資産クラス（株式、債券、不動産など）
- 位置: リスクとリターンの関係で配置
